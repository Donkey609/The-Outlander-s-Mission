This project was developed in collaboration with Angelie Melissa as our final project for I2P2.

1. Description
     The Outlander's Mission is a turn-based RPG where the main character embarks on a series of
   quests to rescue a princess. The game features character movement and exploration,
   a turn-based combat system, an inventory system for managing items, and a health system that
   tracks the player's survival throughout the adventure. Players must complete quests, battle enemies,
   collect useful items, and progress through different areas as they work toward saving the princess.

2. Features
   - Turn-based combat system with multiple enemy types
   - Player movement and exploration across different areas
   - Inventory system for collecting and using items
   - Health and damage management for both players and enemies
   - Quest-based progression centered around rescuing the princess
   - Interactive UI for combat, inventory, and player status
